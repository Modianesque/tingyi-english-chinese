# 听译：实时英语转中文

一个免安装的浏览器小工具，支持英语语音实时识别、中文翻译，也可粘贴英文文本翻译。页面已适配手机屏幕，并带有可安装的渐进式网页应用（PWA）配置。

## 启动

电脑上双击 `index.html` 即可使用文本翻译，不需要安装 Python。

手机使用方式：把整个文件夹放到一个支持 HTTPS 的静态网站托管服务，然后用手机浏览器打开该 HTTPS 地址。语音识别在各浏览器的支持程度不同；若 iPhone Safari 无法启动实时识别，可点下方输入框，使用 iPhone 键盘上的麦克风听写英语，再按“翻译”。页面顶部的“添加到主屏幕”按钮可触发浏览器安装提示；iPhone/iPad 若未弹出提示，请用 Safari 的分享菜单选择“添加到主屏幕”。

此文件夹已附 GitHub Pages 自动发布流程。上传到 GitHub 仓库的 `main` 分支后，在仓库设置的 Pages 区域选择 GitHub Actions，即可发布为 HTTPS 网站。

仅把 HTML 文件发到手机或在手机上打开 `file://` 地址，不能保证麦克风语音识别可用。当前工作区包含 PWA 文件，但还没有公开 HTTPS 网址；要在手机上访问，需要先托管这些文件。

## 说明

- 语音识别使用浏览器提供的 Web Speech API，建议使用最新版 Chrome 或 Edge。
- Web Speech API 并非所有主流浏览器都支持；部分浏览器会把音频发送到在线识别服务，因此语音功能不能离线使用。
- 中英翻译调用 MyMemory 公共翻译接口，需要联网；公共服务可能限流或不可用。
- 语音识别和翻译内容会交给相应的浏览器语音服务及翻译服务处理。请勿输入或朗读敏感信息。
- 这是轻量原型，适合个人试用。若需要稳定商用、会议字幕、多说话人或离线翻译，可再接入付费语音识别与翻译 API。
